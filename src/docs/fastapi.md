# FastAPI: Введение

## Что такое FastAPI?

**FastAPI** — это современный, высокопроизводительный веб-фреймворк для создания API на языке Python 3.7+ на основе стандартных типов Python.

Он был создан для того, чтобы объединить высокую скорость разработки с высокой производительностью выполнения, часто сравниваясь по скорости с NodeJS и Go.

## Ключевые особенности

- 🚀 **Высокая производительность**: Один из самых быстрых Python-фреймворков благодаря Starlette и Pydantic.
- 📝 **Автоматическая документация**: Встроенная генерация Swagger UI и ReDoc для интерактивного тестирования API.
- 🛡️ **Валидация данных**: Использование типов Python и библиотеки Pydantic для строгой проверки входящих данных.
- ⚡ **Асинхронность**: Полная поддержка `async` и `await` для обработки асинхронных запросов.
- 🏗️ **Минимализм**: Легковесный фреймворк, который легко интегрируется с другими библиотеками.

## Основные компоненты

| Компонент | Описание |
|-----------|----------|
| **Path Operations** | Декораторы (`@app.get`, `@app.post`) для определения маршрутов и методов HTTP. |
| **Pydantic Models** | Классы для определения структуры данных, валидации и сериализации JSON. |
| **Dependency Injection** | Система внедрения зависимостей для управления общими ресурсами (БД, авторизация). |
| **Middleware** | Компоненты для обработки запросов на этапах до и после их обработки (CORS, логирование). |

## Пример простого API

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str = None):
    return {"item_id": item_id, "q": q}
